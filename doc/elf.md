### elf, the programming language.


### Please Note The Following:
This project is unreleased, meaning
that it is not meant for public
consumption, yet... there are many
incomplete features and possibly
many, many bugs... use at your
own risk.


### Basic Feature Overview

- Closures
- Meta-tables
- Operator Overloading
- Dynamic Code Execution
- Versatile
- Automatic Memory Management
- Dynamic Symbol Linking
- Cross-platform (WEB) Enabled
- Simple And Embeddable
- A Joy To Program In


### About

Unlike many other languages, which are
in their proper right to be as they wish,
elf is meant to be a whimsical programming
language, that aims to recapture the
magic and fun of programming.
