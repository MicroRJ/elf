example.elf

Familiar syntax, first-class functions, and one table type for indexed and keyed data.

project := {
	name = "manny",
	sources = {
		"src/main.c",
		"src/build.c",
	},
}

objects := project.sources:map(fun(source) {
	ret source:replace(".c", ".obj")
})

elf is consistent. Arrays, maps, and records are different ways of using the same table value.

color := {"red", "green", "blue"}
color.name = "primary"
color.[200] = "ok"

color[0]    // "red"
color.name  // "primary"
color.[200] // "ok"

elf is embeddable. The core is a static library with a public C API for compiling source, calling functions, and exchanging values.

elf is practical. Optional batteries provide files, paths, processes, environments, serialization, time, and randomness.
